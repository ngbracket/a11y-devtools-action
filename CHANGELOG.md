# Changelog

## 1.0.0 (unreleased)

First release. Runs `@ngbracket/a11y-devtools` 0.18.0 report mode on an Angular dev build: starts the dev server, scans the listed routes, comments on the pull request, writes the job summary, uploads Markdown, JSON and HTML reports, and fails the check at the `fail-on` level. Supports a baseline, dark mode, and the keyboard and focus-trap checks.
